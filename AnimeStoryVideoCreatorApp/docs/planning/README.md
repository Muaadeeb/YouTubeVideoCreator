# Planning & Notes

This folder is the shared space for plans, design documents, roadmaps, and notes between the developer and Grok.

## Purpose
- Design documents and architecture decisions
- PR plans and implementation roadmaps
- Progress notes and iteration tracking
- Ad-hoc research or decisions

## Conventions
- Use clear, descriptive filenames (e.g. `Design-FeatureName.md`, `PR-Plan-StoryGeneration.md`, `Notes-2026-05-28.md`)
- Keep individual files focused
- Update the status (Draft / In Progress / Approved / Superseded) at the top of major documents

## Current Documents
- `Current-Status-And-Action-Plan.md` — **Living agenda**: audited feature status + phased action plan / session agendas
- `Grok-Capabilities-And-Limits.md` — **Living**: Grok/xAI can vs cannot (API features + content limits). Re-verify when models/policy change.
- `Design-AnimeStoryVideoCreator.md` — Full implementation design document (approved, May 2026; native Imagine video supersedes slideshow-only MVP where possible)
