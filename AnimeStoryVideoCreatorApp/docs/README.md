# Docs

This folder contains documentation, plans, and notes for the **AnimeStoryVideoCreatorApp** project.

It serves as the shared workspace between the developer and Grok for keeping important planning artifacts organized and discoverable.

## Folder Structure

| Folder            | Purpose |
|-------------------|---------|
| `planning/`       | Major planning documents, design specs, PR plans, architecture decisions, and roadmaps. These are the more formal, longer-lived documents. |
| `notes/`          | Lightweight scratch notes, quick thoughts, meeting notes, ad-hoc research, and temporary ideas. |

## Guidelines

- **planning/**: Use descriptive filenames and keep a status header (e.g. `Draft`, `In Review`, `Approved`, `Superseded`) at the top of each document.
- **notes/**: More casual — feel free to create short-lived files here.
- Both the developer and Grok should feel free to add new `.md` files as needed.
